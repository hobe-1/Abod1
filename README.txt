نشر موقع بوفية توب كبدة

1) ارفع index.html إلى مستودع GitHub الخاص بالموقع.
2) استبدل ملف index.html القديم بهذا الملف.
3) انتظر حتى يكتمل GitHub Pages ثم افتح رابط الموقع وجرب الطلب.
4) إذا لم يظهر الموقع، تأكد من إعدادات Pages في المستودع.

تنبيه: لم يتم اختبار اتصال Firebase الفعلي من هذه النسخة؛ اختبر حفظ طلب تجريبي بعد النشر.
